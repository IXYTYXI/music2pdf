同一作品的所有录音和总谱放在同一个作品文件夹。先检查资料，再按作品划分训练、验证和测试集合。

03　划分数据集

按独立作品组计数，不按录音数量随机切分。相同内容的重复文件会绑定分组；小数据集会调整数量，确保三组都非空。改动文件后请重新扫描。

文件预览

选择作品查看所有版本；音频可试听，PDF 可预览。格式检查不代表内容已验证。
