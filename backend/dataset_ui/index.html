把不同演奏，整理成可追溯的数据

同一作品的所有录音和总谱放在同一个作品文件夹。先检查资料，再按作品划分训练、验证和测试集合。

01　选择数据源

支持 R2 S3 地址 + 桶名 + 目录前缀。私有桶需凭据；可记住连接，凭据保存到系统钥匙串 / 凭据管理器，重启后无需重填。

仅下载选中的作品到本机缓存，不修改云端文件。下方清洗和划分只包含已缓存的资料。

02　检查作品与版本

作品录音 / 乐谱状态
选择目录并扫描后，这里显示真实文件。

03　划分数据集

按独立作品组计数，不按录音数量随机切分。相同内容的重复文件会绑定分组；小数据集会调整数量，确保三组都非空。改动文件后请重新扫描。

文件预览

选择作品查看所有版本；音频可试听，PDF 可预览。格式检查不代表内容已验证。
