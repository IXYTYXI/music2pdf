# IMSLP automatic collector implementation plan

Goal: Discover works without user-supplied links, collect downloadable scores and recordings, and use the existing dataset directory contract.
Architecture: A Python CLI uses an official catalog adapter, HTML asset parser, polite HTTP transport and SQLite durable queue. The workbench scans the same root; no frontend deployment is needed.
Tech stack: Python 3.11+, requests, BeautifulSoup, SQLite, unittest.

Approved scope: automatic discovery, composer/instrument/both-media filters, metadata preservation, bounded downloads, persistent progress, optional cookies. Commercial streaming remains metadata only. Matching is at work level, never a claim of aligned training labels.
